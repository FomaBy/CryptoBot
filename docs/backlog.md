## Контракт задачи для будущего сайта

Обязательные поля: `task_id`, `account_id`, creator/authorizer, R-IDs, goal, allowed scope/actions, priority, dependencies, acceptance/evidence schema, risk class, applicable policy/version, resource budget, lease owner/expiry/fencing token, attempts, status/reason и timestamps. Links связывают task с branch, commit, PR, test run, staging/deployment и соответствующей strategy version.

Владелец может создавать задачи; AI может предлагать новые, но предложение не выдаёт полномочий. Только server policy переводит допустимую задачу в READY. Claim атомарен; устаревший worker не коммитит статус и не деплоит по истёкшему lease. Крупная/неопределённая задача сначала разбивается на проверяемые части. Зависимость DONE валидируется evidence, а не текстом ответа AI.

Низкорисковый autodeploy — будущий opt-in policy mode для узкого класса (например, текст/визуальное оформление вне auth/wallet/signature/approval/risk UI). Файл frontend сам по себе не low-risk: изменение сообщения подписи может фишить или менять смысл согласия. Diff classifier оценивает фактические пути, capability и воздействие; dependencies/build scripts учитываются. Неизвестный риск, tenant границы, signer/risk/promotion/evaluator/CI controls, secrets, schema migration и перевод денег требуют review. Trusted evaluator и enforcement CI неизменяемы для worker; repo scripts выполняются без его privileged credentials. Задачи с данными рынка не могут расширить права.

Кандидат реализации development worker — отдельный server job с [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk) или [non-interactive exec](https://learn.chatgpt.com/docs/non-interactive-mode), изолированным workspace, структурированным результатом и ограниченными инструментами. Astra сохраняется как выбранный пользовательский руководитель разработки; доступность серверного runtime, модель и способ оплаты ещё проверяются. Ключ провайдера выдаётся изолированному agent invocation/proxy, не среде repository build/test. Текущий чат не является постоянно работающим сервером. Расходы DevAI учитываются отдельно от trading equity; запрос не экономить токены разработки не равен бессрочному operational budget.

Определение DONE: acceptance выполнены, необходимые checks успешны, артефакт существует в нужной среде, R-статусы/журнал обновлены, ограничения указаны. Commit не означает deployment; deployment не означает разрешение live; profitable backtest не означает live readiness.
